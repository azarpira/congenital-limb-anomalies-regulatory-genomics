# Regulatory Genomic Architecture of Congenital Limb Anomalies

This repository contains the code, figures, and supplementary material accompanying the manuscript:

"Non-coding Regulatory Variation in Congenital Limb Anomalies Reveals GATA6, HNF1B and SMAD4 as Developmental Bridge Transcription Factors"

## Contents

- GWAS variant annotation
- TF motif disruption analysis
- HPO enrichment analysis
- TF-HPO network construction
- Permutation-based hub validation

## Data source

FinnGen phenotype:
finn-b-Q17_OTHER_CONGEN_MALFO_LIMBS
